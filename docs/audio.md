# Audio plan

AI-generated music is usually weak for a cohesive game score; plan for **placeholder SFX** now and a **composer or licensed pack** later.

## Tools & sources

| Tool / source | Use | License notes |
|---------------|-----|----------------|
| [jsfxr](https://github.com/jchrisos/jsfxr) / [sfxr](https://www.drpetter.se/project_sfxr.html) | UI & hit SFX | Open / permissive |
| [Freesound](https://freesound.org) (CC0 filter) | One-shots, ambience | Per-sound license |
| [Bosca Ceoil](https://boscaceoil.net) | Chiptune sketches | N/A (you own exports) |
| [BeepBox](https://www.beepbox.co) | Short loops | N/A |
| CC0 pack libraries | Placeholder beds | Check pack license |
| Composer (later) | Theme & dungeon suites | Work-for-hire / contract |

Log every file in `assets-licenses.md` before import.
